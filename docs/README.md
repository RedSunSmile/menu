## 기능 목록
- [x] 카테고리 메뉴 요구사항을 등록한다.
- [x] 시작 문구를 출력한다.
- [x] 코치 이름을 입력 받는다.
- [x] 코치 이름은 2~4 글자인지 검증한다.
- [x] 코치가 최소 2~5명 식사 함께 하는지 검증한다.
- [x] 먹지 못하는 메뉴가 없으면 빈값 입력한다.
- [x] 각 코치에게 못 먹는 메뉴를 입력받는다.
- [x] 각 코치가 0~2까지 못먹는 메뉴가 있는지 검증한다.
  ex) "구구(이)가 못 먹는 메뉴를 입력해 주세요."
- [ ] 월~금 5일에 대해 카테고리와 메뉴를 추천한다.
- [x] 카테고리를 무작위로 정한다 - (Randoms.pickNumberInRange)
- [x] 카테고리가 이미 2회 나왔으면 다시 뽑는다.
- [x] 카테고리에서 메뉴를 뽑는다 - (Randoms.shuffle -> get(0))
  ex) String menu=Randoms.shuffle(menus).get(0);
- [ ] 이미 추천한 메뉴면 다시 섞는다.
- [ ] 못먹는 메뉴면 다시 섞는다.
- [ ] "메뉴 추천 결과입니다."를 출력한다.
- [ ] 요일 행을 출력한다
  ex) [ 구분 | 월요일 | ...]
- [ ] 카테고리 행을 출력한다.
- [ ] 코치별 메뉴 행을 출력한다.
- [ ] "추천을 완료했습니다."를 출력한다.
- [ ] 잘못된 입력이면 [ERROR] 메시지를 출력하고 그 부분부터 다시 입력받는다.
