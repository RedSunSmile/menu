## 점심메뉴추천 기능
- [ ] 각 코치 월~금 카테고리 먹을 메뉴 추천
- [ ] 코치이름 최소 2~ 최대 4글자 유효성검사
- [ ] 코치들 최소 2~최대 5 함께 식사 유효성검사
- [ ] 최소0~최대2개 못먹는 메뉴( , 구분)
- [ ] 먹지 못하는 메뉴 없으면 빈값 입력
- [ ] 한주에 같은 카테고리 최대 2회 까지만 가능
  ->각 코치는 한주에 같은 메뉴를 두번 먹지 않는다
  ex) 제임스: 비빔밥, 김치찌개, 스시, 가치동, 짜장면 (매일 다른 메뉴를 먹으므로 가능)
  ex) 포코: 비빔밥, 김치찌개, 스시, 가치동, 짜장면 (제임스와 메뉴가 같지만 매일 다른 메뉴를 먹으므로 가능)
- [ ] 카테고리가 이미 2회 나왔으면 다시 뽑는다
- [ ] 이미 추천한 메뉴면 다시 섞는다
- [ ] 못 먹는 메뉴면 다시 섞는다
- [ ] 잘못된 값 입력 시작 [ERROR] 로 시작 에러메시지 출력 후 그 부분부터 다시 입력
- [ ] 추천 카테고리(Randoms.pickNumberInRange()) 생성이용
- [ ] 정해진 카테고리(Randoms.shuffle(menus).get(0)) 이용하여 임의순서 섞고 맨 앞 하나
- [ ] 메뉴 추천 받을 코치 이름 입력
- [ ] 각 코치 못 먹는 메뉴 입력
- [ ] 점심 메뉴 추천을 시작합니다 출력
- [ ] 메뉴 추천결과입니다 출력
- [ ] 요일 구분 출력
- [ ] 카테고리 출력
- [ ] 코치별 메뉴출력
- [ ] 추천을 완료했습니다 출력개
